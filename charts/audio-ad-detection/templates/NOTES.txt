audio-ad-detection (headless worker)

The worker has no UI and no ingress (the proxy leg is N/A by design).
It is reached in-cluster only:

  kubectl -n default port-forward svc/home-audio-ad-detection 8080
  curl localhost:8080/healthz   # process + snapclient child alive
  curl localhost:8080/readyz    # pipe + model + query loop + broker session
  curl localhost:8080/metrics   # Prometheus text exposition

Service: home-audio-ad-detection (ClusterIP, port 8080).
PVC: audio-ad-detection (10Gi, RWO, mounted at /models) —
holds the model snapshot + the candidate dir (model + <=2 Gi candidates).
