into a two-controller chart — `runner-dev` (the existing registration) and
`runner-infra` (NEW, conflict ruling 2) — keeping run 2's established

correctness port), the k3s MTU values-header warning, and the doc ports
(run 1's RESEARCH.md → `RESEARCH-dind-supplement.md` + pointer line). Run 3's
k8s-plugin implementation is NOT ported (ruling 1: DinD sidecar wins).
