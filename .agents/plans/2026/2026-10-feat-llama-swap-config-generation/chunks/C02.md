# C02: declared-half render — roster schema + Helm templates + value conversion (golden parity)
size: L   wave: 1   depends_on: []

## Goal
Replace the hand-edited llama-swap YAML with a compact desired-state schema in
chart values, rendered by Helm into today's exact config surface. Zero
model-ID/alias/matrix changes; the rendered `config.yaml` must be semantically
identical per cluster to the captured golden (pre-change render).

## Tasks
- [ ] Golden capture (BEFORE editing templates — commit the files): render current
      chart+gpu and chart+gpu-ai per the plan's extract-and-render Commands; store as
      `charts/llama-swap/tests/golden/gpu.config.yaml` and `gpu-ai.config.yaml`
      (config.yaml data extracted). These are the immutable parity spec.
- [ ] Schema (chart `values.yaml` under `config:`):
      - top-level scalars + `macros:` unchanged (single source for both halves).
      - `filterPresets: {vl-workload: {setParamsByID: {"${MODEL_ID}:tags": ..., "${MODEL_ID}:caption": ...}}}`
        (replaces the `&vlWorkloadFilters` anchor; per-model `filters: vl-workload`).
      - `models.<id>` entries become declarative: `hf` (`org/repo:TAG`), `draft`
        (`-hfd` ref), `spec` (`{type, draft_n_max, draft_p_min?}`), `use: [macro names]`
        (ordered), `flags: |` raw extra lines, `cmd: |` raw escape hatch, `disabled: "<reason>"`,
        plus passthrough fields `name description ttl aliases capabilities checkEndpoint
        proxy env unlisted filters concurrencyLimit sendLoadingState timeouts`.
        Precedence `disabled > cmd > (hf/draft/spec/use/flags)`. `proxy` defaults to
        `http://localhost:${PORT}`; omitted `ttl` stays omitted (inherits globalTTL).
      - cmd composition: `${server-cmd}` line first, then `-hf`, `-hfd`, then each `use`
        macro's expansion, then `spec` flags (`--spec-type X --spec-draft-n-max N ...`),
        then `flags` verbatim. (llama.cpp is rightmost-wins; golden parity compares
        flag-token sets, not order.)
      - `disabled` renders the lab's fail-fast shape verbatim:
        `/bin/sh -c "echo '<id> disabled on this box: <reason>.' >&2; exit 1"` + the
        per-cluster description the current gpu entries use.
- [ ] New template `charts/llama-swap/templates/_helpers-llama-swap.tpl` + rewrite
      `templates/configmap-llama-swap.yaml` (currently `toYaml .Values.config`) to render
      the full config from the schema. Raw `cmd` entries (whisper bootstrap,
      qwen38-rana multi-curl) pass through untouched, incl. inline comments.
- [ ] Convert `charts/llama-swap/values.yaml` models (all 40 entries) into the schema.
      Raw-`cmd` keeps: `whisper-large-v3` (and its `# NOTE` SanitizeCommand comments as
      values comments), nothing else in the chart.
- [ ] Convert `services/gpu/prod/values.yaml` `llama-swap.config.models`: the tuned
      `qwen3.6-35b-a3b-q8` cmd → schema fields (its flags incl. `--no-mmproj`, `-np 1`,
      `--cache-reuse 256`, `-ub 1024`); the 6 DISABLED entries → `disabled:` + description.
- [ ] Convert `services/gpu-ai/prod/values.yaml`: 20 models (incl. `qwen38-rana` raw-cmd
      escape hatch — one-physical-line exec invariant preserved), `q38-*`/`q36-*` macros,
      `matrix`, `hooks.on_startup.preload` — same shapes, schema-native where possible.
      Keep every explanatory values-comment (they are the surviving rationale layer).

## Acceptance criteria
1. `helm lint charts/llama-swap` + all four renders in Commands pass.
2. Parity: for gpu and gpu-ai, the new render vs golden — normalized-equal: per-model cmd
   flag-token multisets, `name/description/ttl/proxy/aliases/capabilities/checkEndpoint/
   filters/env` deep-equal, `macros` deep-equal (whitespace-normalized), `matrix` deep-equal,
   `hooks` deep-equal, top-level scalars deep-equal. Model ID sets equal EXACTLY.
3. Consumer-critical IDs present per cluster: gpu = chart 40 IDs; gpu-ai = those 40 (6
   overrides merged from gpu-style keys stay chart-default there) + the 16 gpu-ai-local IDs;
   aliases intact: `qwen3-vl-4b`, `qwen3-vl-8b`, `qwen3-vl-30b-a3b`, `qwen3.8`,
   `local/qwen3.8-27b`; `:tags`/`:caption` setParamsByID keys auto-alias for all 12 VL
   `vl-workload` models; matrix var→model referential closure (v262 load rule).
4. `gpu`-render fail-fast check: the 6 DISABLED entries render `/bin/sh -c "echo ... >&2; exit 1"`
   cmds with byte-identical echo strings to golden.
5. No `OVERRIDE_*` sentinel leakage; `bitwardenIds`/`hf-token` wiring untouched.
