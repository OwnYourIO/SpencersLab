size: M   wave: 3   depends_on: [C03]

## Goal

remote MCP servers, grant pipeline agents access to them (they otherwise fall
through to `ask` = blocked in unattended runs), and document them in the rules
source so the regenerated AGENTS.md lists them.

## Notes for dev
- rulesync.jsonc deliberately keeps mcp/permissions/hooks features OFF; run
  plain `npx rulesync generate` (no `--features` widening) and it will only
  emit rules/subagents/commands/skills. Never `rulesync gitignore` (would gitignore
  AGENTS.md — Hard rule).
- `.agents/agents` is a symlink to `.opencode/agents`; editing `.rulesync` and
  regenerating is the sanctioned path (Hard rule: never hand-edit generated).
- The `dev*` allow is required because the OpenCode v2.1.4 runtime HONORS the
  `ask` fallthrough in unattended pipeline runs — without it `dev-boards`/etc.
  calls block. Documented so a future reader doesn't "clean up" the rule.
- Commit is on the feature branch (never merge/push to main — Hard rule);
  machine-global config sync is user-owned (DECISIONS.md).
