size: M   wave: 2   depends_on: [C01, C02]

## Goal
Add the four `hivetools.mcp` entries (playwright, renovate, searxng, boards) to
the dev umbrella, the two ExternalSecret templates the entries consume
(`github-mcp`, `wekan-mcp`), the umbrella sentinels, and the real UUIDs/placeholders
in custom-values — so ArgoCD renders `MCPServer mcp-<name>` + ingress paths at
`https://mcp.dev.scifi.farm/<name>`.

## Resolved input (OQ1 — user decision 2026-10-24, approval round)
`boards.WEKAN_BASE_URL` is NOT hardcoded in values: it is read from the
**URI field of the Bitwarden LOGIN item** `d8e2b2ca-…` via the `bitwarden-uri`
SecretStore (pattern: `secret-homeassistant-mcp.yaml` lines 29-39 — same item,
second store). Dev therefore targets whatever instance the user records in the
item's URI (dev has no wekan; the URI is expected to be a lab wekan host with
`WITH_API=true` and password login). `boards` ships **enabled: true**.
