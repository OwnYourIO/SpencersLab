## Notes for dev
- `export PATH=$HOME/.local/bin:$PATH`; the runner chart's dependency
  (app-template `5.0.1`) comes from an **https** helm repo, not OCI — the
  suite's skip-not-fail guard covers a flaky fetch, not a licence.
- gpu's cluster annotation mechanism (`OVERRIDE_VIA_CLUSTER_ANNOTATION`, file
  header) is the **legacy** path and deliberately NOT used here — the runner
  UUID follows the current `custom-values` standard (the file's own comment
  records that split).
- Do not "align" the gpu slice URL with dev's in-cluster value or with the
  infra cluster's own in-cluster service; the whole point of the slice is that
  gpu reaches the instance through its **public** route (§R3 reachability is
  live-proven from gpu pods, and gpu's coderd already rides this exact host).
- Registration troubleshooting truth for the review notes: a `connection
  "default" is invalid: 'uuid' is empty` loop = bad/absent UUID; online-then-
  offline flapping = URL/instance mismatch (record is on infra) or network,
  not repo config.
