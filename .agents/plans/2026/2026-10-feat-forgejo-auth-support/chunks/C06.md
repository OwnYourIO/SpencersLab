# C06: workspace SSO polite gate — per-user token wins over the PAT helper (dev pair)
size: M   wave: 4   depends_on: [C04]

## Goal

Turn the dev-coder workspaces' git identity on the dev forge into the
per-user SSO token whenever the user has approved, while keeping the shipped
C02/C03 PAT plumbing as bootstrap/fallback — the user's "polite gate +
banner" ruling. `workspace-startup.sh` probes `coder external-auth
access-token <provider-id>` (v2.35.2 contract, docs-verified: validated token
to stdout exit 0; else the authentication URL to stdout exit 1): approved ⇒
PAT helper NOT wired (and stale entries unset) so Coder's agent-side
`GIT_ASKPASS` answers with the per-user token — unapproved ⇒ banner prints the
approval URL and the bot PAT fallback keeps the boot fully working. The
kubernetes-hardened template opts a workspace generation in via one new
literal env.

Dependency on C04: the provider-id literal `forgejo` must exist in the chart
template (c-sso drift check compares both sides), and without the C04
provider the probe can only ever take the fallback path — the chunk's tests
would be asserting a permanently-dead branch.

## Notes for dev

- `set -eu` + command substitution: probe via `if sso_token=$(...); then`
  (the `if` absorbs the exit 1); NEVER a bare `var=$(cmd)` of a failing
  command — it aborts the boot (this is precisely the "fail raw" the ruling
  forbids).
- `git config --unset-all` on a missing key exits non-zero (git ≥ 2.26
  exit 5) — `|| true` it.
- The unset-on-approved is load-bearing across reboots: `~/.gitconfig`
  lives on the home PVC, so a PAT helper wired before the user approved
  would otherwise shadow askpass forever (research §E: helpers answer
  before askpass).
- The SSO token is good ~1h with a ~30d rotating refresh managed by
  coderd; only git-over-https in terminals/agent apps consumes it via
  askpass. `fj` keeps the bot PAT (its token store is static; seeding an
  hour-lived token there would rot mid-session — DECISIONS 2026-10-24
  replan). OpenChamber keeps its per-user PAT cards, untouched.
- Do not touch: canonical/GITHUB blocks' bodies, the waiver/bind posture,
  seed/identity sections, `wire_forgejo`'s git-before-fj ordering, or
  `services/gpu/**` (C05). Legacy `kubernetes/` template stays retired from
  scope per DECISIONS.
- The banner is boot-log UX: keep it inside the existing `log`/echo idiom so
  `coder ssh` and pod logs show it; do not block on it.
