# C01: OpenChamber/Forgejo-capable image pins
size: S   wave: 1   depends_on: []

## Goal

Move the workspace image to the OpenChamber release that ships the Forgejo git
host and to the OpenCode line it requires: `@openchamber/web` 2.4.0 → **2.5.1**,
`@opencode/cli` 2.0.32 → **2.1.4** (floors: 2.5.1 introduced Forgejo support;
OpenChamber ≥2.5.1 needs OpenCode ≥2.1.0, bundles 2.1.3).

## Tasks

- [ ] `containers/coder-workspace/Dockerfile`: `ARG OPENCODE_VERSION=2.0.32` →
  `2.1.4`; `ARG OPENCHAMBER_VERSION=2.4.0` → `2.5.1`. Change ONLY the version
  values — the `# renovate: datasource=npm depName=@opencode/cli` and
  `# renovate: datasource=npm depName=@openchamber/web` comment lines and the
  surrounding comments stay byte-identical (attribute order is part of the
  renovate custom-manager extraction contract).
- [ ] `tests/coder-workspace/image-structure.sh`: update the `PIN` map
  expectations `[OPENCODE_VERSION]` and `[OPENCHAMBER_VERSION]` to the new
  values (the `COMMENT_RE` regexes stay untouched).
- [ ] `tests/renovate/dockerfile-pins.sh`: update the two npm tuples in
  `EXPECTED_NEW` to `2.1.4` / `2.5.1` (depName/datasource unchanged).
- [ ] If a newer npm version than 2.1.4/2.5.1 exists at implementation time,
  take the newest ≥ the floors and mirror it into both test files (criterion 4).

## Acceptance criteria

1. `grep -E '^ARG (OPENCODE|OPENCHAMBER)_VERSION=' containers/coder-workspace/Dockerfile`
   shows exactly `OPENCODE_VERSION=2.1.4` and `OPENCHAMBER_VERSION=2.5.1`
   (or the newer chosen versions, same values in the tests).
2. Each bumped ARG still carries its renovate comment on the immediately
   preceding line, unchanged — `bash tests/coder-workspace/image-structure.sh`
   proves it.
3. `bash tests/coder-workspace/image-structure.sh` => exit 0.
4. `bash tests/renovate/dockerfile-pins.sh` => exit 0, and
   `curl -fsS https://registry.npmjs.org/@openchamber/web/latest` /
   `.../@opencode/cli/latest` confirm the chosen versions exist and are ≥
   2.5.1 / ≥ 2.1.0 respectively.
5. No other Dockerfile line changes (diff shows exactly two version edits).
