# C05: Give the runner process the dind socket group (fix docker-socket EACCES)
size: S   wave: 1   depends_on: []   owner: agent   shape: recommended (a) — **user fix-shape pick pending** (plan Open question 1); if the answer is not (a), this file is replanned, not improvised.

## Goal
The uuid gate is cleared (C01 done, 2026-11-02: filled render, bounced 00:46:35Z, validation passes) and the daemon now dies at RESEARCH F2's next stage: `cannot ping the docker daemon. is it running? permission denied while trying to connect to the docker API at unix:///var/run/docker.sock`. Cause: `docker:29.9.2-dind`'s base (`29/cli`) pre-adds group `docker` at **fixed gid 2375** (upstream `addgroup -g 2375 -S docker`, verified 2026-11-02); dockerd serves the socket `root:docker 0660`; the uid-1000 runner holds no such group. `fsGroup: 1000` cannot help — it chowns the volume at mount, while the socket file is created *after* by dockerd with its own group. The fix: make the runner process a member of the daemon's socket group — the capability `DOCKER_HOST` was always wired for.
