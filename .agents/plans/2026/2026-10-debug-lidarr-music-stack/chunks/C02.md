# C02: Lidarr fix — directory-mount the betanin Secret outside /config
size: S   wave: 2   depends_on: [C01]

## Goal
Stop `media-lidarr`'s deterministic `StartError` (exit 128: runc "not a
directory" mounting the `BETANIN_API_KEY` subPath of the optional `betanin`
Secret onto `/config/secrets/betanin/api_key`), so the pod starts and the
ArgoCD app `media` goes Healthy — via GitOps changes on this branch only.

## Tasks
- [ ] `services/media/prod/values.yaml` — in the `lidarr:` block's
      `volumeMounts`, replace the `betanin-secret` entry
      ```yaml
      - name: betanin-secret
        mountPath: /config/secrets/betanin/api_key
        subPath: BETANIN_API_KEY
      ```
      with a whole-volume directory mount:
      ```yaml
      # Whole-Secret directory mount: file subPaths of an optional Secret are
      # not materialized while the Secret is absent and left the container in a
      # deterministic StartError (runc "not a directory", 14 restarts) — a
      # directory mount tolerates empty/optional state and never collides with
      # the /config PVC subtree. Key visible as /betanin-secrets/BETANIN_API_KEY.
      - name: betanin-secret
        mountPath: /betanin-secrets
      ```
      Keep the `volumes` entry (`secretName: betanin`, `optional: true`) and all
      other mounts (`/config`, `/media/`, `/config/scripts/betanin.sh`) untouched.
- [ ] `services/media/prod/templates/configmap-lidarr-betanin-script.yaml` —
      change the key read to `API_KEY="$(cat /betanin-secrets/BETANIN_API_KEY)"`
      and adjust the header comment's path reference (still points at the
      betanin ExternalSecret mount; the filename is the Secret key name now).
- [ ] Validate (the "Commands" in the plan file — run all before commit):
      `helm dependency update services/media/prod`; `helm lint services/media/prod`;
      both `helm template … --show-only` renders; zero `OVERRIDE_` and zero
      `/config/secrets/betanin` hits in rendered output; image still
      `lscr.io/linuxserver/lidarr:nightly-version-3.1.6.5078`.
- [ ] Commit on `add-music-to-media` (C01 leaves a clean index), message e.g.
      `fix(media): mount betanin secret as a directory to stop lidarr StartError`.

  timeline, `media-betanin` running with sibling subPath mounts of the same
  Secret, Deployment Available=False since 2026-09-24. The fix removes the
  file-subPath mechanism, not the Secret or the script.
- `optional: true` stays: with the directory mount an absent Secret yields an
  empty dir (pod starts; the script fails loudly at import time) instead of
  blocking the whole pod.
