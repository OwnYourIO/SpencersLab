1. `helm lint charts/mosquitto` + `helm template mosquitto charts/mosquitto` pass; rendered kinds: ConfigMap, Service (ClusterIP, 1883), Deployment/StatefulSet per app-template default (Deployment), emptyDir volumes mounted.
2. `version: 1.0.0` in Chart.yaml (new-chart law); no `OVERRIDE_` strings survive the plain render (the `domain` value must be consumed nowhere or set to `OVERRIDE_VIA_APPSET` only as the repo-standard passthrough that renders unused — if it leaks into output, drop it).
3. Image literally `eclipse-mosquitto:2.0.22`. Pin rationale (record in the values comment, per R2.3): the BARE release stream ends at 2.0.22 — the 2.1.x series is published ONLY with the `-alpine` suffix (`latest = 2.1.2-alpine`); pinning the bare stream stays coherent with the repo's renovate-annotatable convention. dev confirms once via the Docker Hub tags API and records the verdict.
4. drop-ALL capabilities + allowPrivilegeEscalation false present in the rendered CONTAINER securityContext; pod securityContext carries the runAsUser/runAsGroup/fsGroup 1883 + runAsNonRoot trio.
5. No secret/ExternalSecret/custom-values artifacts anywhere in the chart.
