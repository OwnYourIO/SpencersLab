# C01: Pre-flip drift audit + ignoreDifferences hardening + root-autosync runbook
size: M   wave: 1   depends_on: []

## Goal

Make the human's `services.<cat>.selfHeal` flip safe and fully documented: audit the live
root-app trees of every reachable cluster for drift that automated+selfHeal would fight,
add `charts/base` `ignoreDifferences` customizations for every controller-owned drift
writer the audit finds (or record "none found"), and write the operator runbook that flips
all 11 categories from "manual sync" to "push-to-main lands in ≤~3 min" — with preflight,
pilot-then-fleet rollout, verification and rollback.

## Tasks

- [ ] **Audit (read-only, live):** for every cluster in the audit roster — `dev, gpu,
      gpu-ai, grow, home, infra, media, monitoring, proxy-local` (readonly MCP catalog;
      `proxy-remote`, `proxy-backup` = manual-preflight rows) — read the root Application
      and its tree via `tools["readonly-<cluster>-kubernetes"].resources_get`
      (`apiVersion: argoproj.io/v1alpha1, kind: Application, namespace: default`, name =
      category); record per cluster: root `spec.syncPolicy` as observed, `status.resources`
      OutOfSync/degraded list, and **sample child Apps** (`<cat>-<app>`; resources_list +
      a few resources_get) to settle RESEARCH/EXPLORE's open question whether children
      carry automated today. Probe failures (e.g. media ECONNREFUSED) get an honest
      "not reachable — manual preflight" row, never an inferred value.
- [ ] **Classify every drift item** as (a) controller-owned live edit selfHeal would
      revert → needs an ignoreDifferences entry, (b) genuine drift to reconcile at first
      sync → runbook preflight item, (c) noise already covered by the 4 existing
      customizations. Record the classification table + raw probe evidence in the runbook's
      audit appendix.
- [ ] **Harden as dictated:** for every class-(a) writer, extend
      `charts/base/values.yaml` `argo-cd.configs.cm.resource.customizations.ignoreDifferences.*`
      (match the existing jqPathExpressions/jsonPointers style; comments explain WHY).
      If the audit finds none, make no values change and say so in the runbook.
- [ ] **Write the runbook** `.agents/notes/2026-11-12-argocd-root-autosync.md` with
      sections: (1) How sync gating works (annotation gate, exact semantics: automated
      renders only when absent or exactly `"true"`; per-app override in the charts appset;
      both appsets share the service-wide key; gate file paths), (2) Why it was off /
      incident history (k3s 2026-10-20, `charts/base/values.yaml` comment), (3) Pre-flight
      audit results (table above; per-cluster drift to accept/fix first, incl.
      `infra-seaweedfs` pointer to the 2026-11-10 incident notes), (4) Flip list — the 11
      categories with exact annotation keys `services.<cat>.selfHeal` and the note that
      `backups`/`personal` have no root app, (5) Flip procedure per cluster — **human/admin,
      out-of-band**: discover the cluster secret
      (`kubectl -n argocd get secret -l argocd.argoproj.io/secret-type=cluster`), set
      annotation to `"true"` via kubectl patch or ArgoCD UI; warning that DELETING the
      annotation also means ON and that rollback is setting it explicitly to `"false"`,
      (6) Rollout order — pilot ONE cluster (recommend a low-blast one, e.g. monitoring),
      verify, then fleet; per-cluster post-flip verification (root gains
      `syncPolicy.automated`, reaches Synced within ~3 min; then one real push-to-main
      lands without manual action), (7) Rollback (set `"false"`; children/roots both
      revert to manual). Every kubectl/argocd command in the file is marked as
      human-executed — the repo never applies (AGENTS.md).
- [ ] Re-run the plan's full Commands block; append results to this chunk's Notes.

## Acceptance criteria

1. Runbook exists at the exact path and contains the 7 numbered sections above.
2. Flip list covers all 11 appset categories (`dev, gpu, gpu-ai, grow, home, infra, media,
   monitoring, proxy-backup, proxy-local, proxy-remote`) with the exact annotation keys,
   and states `backups`/`personal` have no root app.
3. Gate semantics stated exactly and matching the repo (automated ⟺ annotation absent or
   == `"true"`; per-app override `<cat>.<app>.selfHeal`; both appsets share the
   service-wide key) — reviewer diffs wording against
   `services/infra/prod/templates/appset.yaml:126` and
   `charts/base/templates/appset-charts.yaml:132-138`.
4. Audit appendix has one row per roster cluster (+ the 2 manual rows) with
   {root syncPolicy observed | sampled child state | OutOfSync resources or "none" |
   probe status}; failures recorded as failures; no row inferred from RESEARCH/EXPLORE.
5. Every class-(a) drift writer in the audit table has a corresponding rendered
   `resource.customizations.ignoreDifferences` entry; or the runbook contains an explicit
   "audit found no new drift writers — no values change" statement.
6. Plan Commands all pass (lint 0 failed; template renders; existing 4 ignoreDifferences
   keys intact; 0 `OVERRIDE_` hits).
7. `git diff --name-only` (dev: working tree) touches ONLY the files in scope; no
   ingress/service/proxy values, no new secrets; the runbook's command blocks carry the
   human-executed marker.
