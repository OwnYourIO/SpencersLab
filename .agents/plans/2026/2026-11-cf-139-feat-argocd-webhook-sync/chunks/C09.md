## Acceptance criteria
1. `python3 -m py_compile scripts/argocd-fanout.py` passes; import set unchanged
   (stdlib-only, no additions); roster JSON parses to EXACTLY the five global keys.
2. `bash tests/argocd-fanout/behavior.sh` fully green (legs t1–t13 re-pinned).
3. Happy discovery: 3 fixture pairs (incl. `GPU_AI_TOKEN`/`GPU_AI_URL`) produce 3
   targets with categories `gpu-ai` etc., root_app == category, audit lines exactly as
   before; URL trailing slash normalized (one `/api/v1/...` path byte-per request).
4. Pair-integrity matrix (configured lane, aggregated RED, exit 1): URL-without-TOKEN,
   TOKEN-without-URL, empty TOKEN beside a healthy pair (residue), empty URL, non-JWT
   token, bad-scheme URL, userinfo-in-URL, query-in-URL — each RED names its category
   in the ONE aggregated line; multiple simultaneous violations all listed, sorted.
5. Category law: `GPU_AI` ⇒ `gpu-ai` (single `_` = hyphen separator; mapping injective
   on the hyphen-only category set; env-key uniqueness makes aliasing structurally
   impossible). BROAD-CATCH validation: any key matching `^ARGOCD_SYNC_(.+)_(URL|TOKEN)$`
   whose segment fails the strict charset (`__`, leading/trailing `_`, dots — a typo'd
   workflow enumeration row reaching the job) with a NON-EMPTY value ⇒ config RED
   naming the RAW KEY (never silently unparsed — that would re-open the silent
   cluster-loss class); with an EMPTY value ⇒ ignored (an unattempted residue). Names
   outside the broad shape — the dead `ARGOCD_SYNC_TOKENS` blob included — are ignored
   by construction, never echoed.
6. Kill lane: zero non-empty `*_TOKEN` (URLs populated or not, keys absent entirely, or
   all empty strings — three arms) ⇒ pinned warning at column 0, exit 0, ZERO server
   hits, no other stdout.
7. `--check` (configured lane): OK line + allowed_refs + tunables + NAME/URL table from
   pairs + `pairs: N targets discovered (values never printed)`; zero sockets; exits 1
   via the same integrity matrix when the fleet is broken.
8. Values NEVER echo: fixture token values absent from combined stdout+stderr across
   EVERY leg (t12 sweep), including RED lines; `ARGOCD_SYNC_TOKENS` set to junk beside
   valid pairs is ignored (matches nothing) and never echoed.
9. Ref gate + fan-out semantics unchanged: gate line, root-first→settle→sweep,
   prune query+body, 409-in-progress, isolation (timeout/401/3xx/garbage),
   all-skipped warning, summary with `targets=<discovered>` count — all as shipped.
10. Core-diff proof: `git diff` between shipped and re-cut touches only the input
    surface — the untouched-function list in "Files in scope" shows zero hunks.
11. `tracked_repo` + `allowed_refs` validation behaviors preserved (empty list red,
    non-`refs/` red, `refs/tags/*` red, tunable finiteness/whole-number red).
