size: M   wave: 14   depends_on: [C13]

## Goal
Add the second input channel to `scripts/argocd-fanout.py` without touching a byte of
the validation semantics: when `ARGOCD_PAIRS_FILE` names a file, the pairs map is loaded
from JSON and fed into the EXISTING `discover_targets(source)` — the landed function
already treats its source as a dict (`PAIR_KEY_RE` broad scan over `.items()`), so the
file is just another dict of `NAME -> value` in the same namespace. The env scan stays
the unset/default path (local posture, manual `--check`, and every existing behavior
arm). With OQ-A adopted (recommendation), the roster also gains the `categories`
membership oracle — restoring ruling-(j) loudness for cleanly-deleted pairs in the
blob world.
