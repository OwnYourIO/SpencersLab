# C14: Run registry + zombie firewall + registration-verb tools (B2/B3)
size: L   wave: 4   depends_on: [C06, C08, C12]

## Goal

The two blockers BEFORE leases may die: the durable, cross-process, restart-surviving per-card
RUN REGISTRY (B3 — "which session runs which card", visible to both server processes,
consulted before ANY spawn) and the ZOMBIE FIREWALL re-keyed on it (B2 — a run judged dead
whose successor started must never write into the successor's worktree; today the LOCK_LOST
guard is the only mechanism, and its false-positive storm class must be DESIGNED OUT, RV
§2b.5). The `pipeline_*` tool surface is redefined as registration verbs (names KEPT — the
re-pin-minimizing ruling; `pipeline_heartbeat` RETIRED — liveness is derived from session
records now, never beaten).
