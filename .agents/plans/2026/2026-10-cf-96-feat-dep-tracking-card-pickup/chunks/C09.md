# C09: coder workspace TZ + timestamp pass (OQ4 everything-local, instants preserved)
size: M   wave: 4   depends_on: [C07]

## Goal
Set the coder workspace timezone via the template `coder_agent` env —
`TZ = "America/Denver"` shipped for real (OQ5 ruling) — and convert every
DISPLAYED ISO stamp the pipeline machinery writes to workspace-local ISO-8601
with offset, per the OQ4 ruling "everything incl. machine fields": that
extends to the previously-UTC-only plugin fields (lock-file
`claimedAt`/`heartbeatAt`, audit-JSONL `at`, timeouts.jsonl `at`,
board-context `collectedAt`) alongside the human-facing set. Values that are
INSTANTS stay as they are by definition (epoch-ms fields, mtimes) — an
instant cannot "become local". The reaper's 2 h staleness contract is
verified untouched (AC2).
