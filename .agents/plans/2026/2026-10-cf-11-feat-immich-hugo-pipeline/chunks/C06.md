## Artifacts (site-staging/)

### 1. `.forgejo/workflows/deploy.yml` — delivery (unchanged by the rework)

Contract (dev writes the full YAML to it):
- `on: push: {branches: [main]}` + `on: pull_request: {branches: [main],
  types: [opened, synchronize, reopened]}`.
- `concurrency`: group `${{ github.event_name }}-deploy`,
  `cancel-in-progress: false` (queued runs finish in order → last PR wins).
- One job `deploy`, `runs-on: cf-host` (C03's label — dev validation now, gpu
  prod later; label stays constant), `timeout-minutes: 30`.
- Steps: checkout `fetch-depth: 0` (enableGitInfo needs history) + `lfs:
  true` (real bytes; `.Resize` fails on pointers).
- Branches: push→main: `hugo --gc --minify -b https://curatedforest.com` →
  `netlify deploy --prod --no-build --dir public --site $NETLIFY_SITE_ID
  --message "deploy <short-sha>"`. PR: `hugo -D --gc --minify -b
  https://curatedforest.farm` → same deploy against `$NETLIFY_SITE_ID_FARM`.
- Env: `NETLIFY_AUTH_TOKEN` from secrets; `HUGO_CACHEDIR: /data/hugo-cache`
  (PVC-persistent). NO auto-merge, NO `--build`, NO main writes from PR runs.

### 2. `.forgejo/workflows/sync.yml` — daily Immich sync

Contract:
- `on: schedule: [{cron: "17 5 * * *"}]` — DAILY 05:17 UTC ≈ 23:17 MDT
  (overnight Denver; off-the-hour :17 avoids scheduler hotspots; answer 7) +
  `on: workflow_dispatch: {inputs: {albums: {type: string, required: false,
  description: "comma-separated album names overriding sync-albums.yaml"},
  force: {type: boolean, default: false}}}`.
- `concurrency: {group: immich-sync, cancel-in-progress: false}`.
- One job `sync`, `runs-on: cf-host`, `timeout-minutes: 30`.
- Steps:
  1. checkout default branch, `fetch-depth: 1`, `lfs: false` (existence
     checks work on pointers; new files commit through the LFS filter) +
     `git lfs install --local` first.
  2. `immich-hugo-sync` (baked into the image, C01/C02) with env:
     `IMMICH_URL` (values BG `http://home-immich-server:2283` — the RUNNER'S
     in-cluster view; dev/gpu runners cannot actually reach it until card #88
     resolves the network path → live runs fail loud, fixture tests cover the
     logic; keep the URL a workflow-level env for one-line edits),
     `IMMICH_API_KEY: ${{ secrets.IMMICH_API_KEY }}`, `SITE_DIR: ${{
     github.workspace }}`, `ALBUMS_FILE: ${{ github.workspace }}/sync-albums.yaml`,
     `ALBUMS: ${{ inputs.albums }}`, `FORCE: ${{ inputs.force }}`,
     `STATE_DIR: /data/state`, `OUTPUT_FLAG` temp path.
  3. If flag = changed: `immich-hugo-publish` with `SITE_DIR`, `BRANCH:
     immich-sync`, `FORGEJO_URL`, `FORGEJO_REPO` (`owner/name`, owner = the
     Forgejo ORG — answer 6), `FORGEJO_PAT: ${{ secrets.FORGEJO_SYNC_PAT }}`,
     `SUMMARY` from step 2's stdout. PAT (not FORGEJO_TOKEN) so the PR event
     fires deploy.yml's farm leg (anti-recursion suppression, DECISIONS P5).
  4. Else log "no changes" and exit clean.
- NOTE for reviewers: cadence is daily → one missed schedule = one stale day;
  the watchdog (C05) is the compensating control (answer-7 note).
