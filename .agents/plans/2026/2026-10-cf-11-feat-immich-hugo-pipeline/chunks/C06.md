## Artifacts (site-staging/)

### 1. `.forgejo/workflows/deploy.yml` — delivery (locked deploy model)

Contract (dev writes the full YAML to it):
- `on: push: {branches: [main]}` + `on: pull_request: {branches: [main],
  types: [opened, synchronize, reopened]}`.
- `concurrency`: group `${{ github.event_name }}-deploy`,
  `cancel-in-progress: false` (queued runs finish in order → last PR wins).
- One job `deploy`, `runs-on: cf-host` (C03's label), `timeout-minutes: 30`.
- Steps: checkout with `fetch-depth: 0` (enableGitInfo needs history —
  RESEARCH-curatedforest-repo.md) and `lfs: true` (real image bytes; the
  gallery's `.Resize` fails on LFS pointers).
- Branch: push→main: `hugo --gc --minify -b https://curatedforest.com` then
  `netlify deploy --prod --no-build --dir public --site $NETLIFY_SITE_ID
  --message "deploy <short-sha>"`. PR: `hugo -D --gc --minify -b
  https://curatedforest.farm` then the same deploy against
  `$NETLIFY_SITE_ID_FARM`. Explicit hugo + `--no-build` = deterministic builds
  (DECISIONS; netlify.toml stays for the record / future local builds).
- Env: `NETLIFY_AUTH_TOKEN` from secrets; `HUGO_CACHEDIR: /data/hugo-cache`
  (PVC-persistent image/module cache across runs).
- NO auto-merge, NO main writes from PR runs, NO `--build` flag.

### 2. `.forgejo/workflows/sync.yml` — the Immich sync (locked triggers)

Contract:
- `on: schedule: [{cron: "17 * * * *"}]` (hourly BG — Open question 7) +
  `on: workflow_dispatch: {inputs: {albums: {type: string, required: false,
  description: "comma-separated album names overriding sync-albums.yaml"},
  force: {type: boolean, default: false}}}`.
- `concurrency: {group: immich-sync, cancel-in-progress: false}`.
- One job `sync`, `runs-on: cf-host`, `timeout-minutes: 30`.
- Steps:
  1. checkout default branch, `fetch-depth: 1`, `lfs: false` (existence checks
     work on pointer files; only NEW images get committed → LFS clean filter
     uploads them). `git lfs install --local` first (filter must be active for
     commits).
  2. `immich-hugo-sync` (baked into the image, C01/C02) with env:
     `IMMICH_URL: http://home-immich-server:2283` (runner pod on home cluster
     — same-namespace URL proven by charts/immich-analyze), `IMMICH_API_KEY:
     ${{ secrets.IMMICH_API_KEY }}`, `SITE_DIR: ${{ github.workspace }}`,
     `ALBUMS_FILE: ${{ github.workspace }}/sync-albums.yaml`, `ALBUMS: ${{
     inputs.albums }}`, `FORCE: ${{ inputs.force }}`, `STATE_DIR:
     /data/state`, `OUTPUT_FLAG` to a temp path.
  3. If flag = changed: `immich-hugo-publish` with `SITE_DIR`, `BRANCH:
     immich-sync`, `FORGEJO_URL`, `FORGEJO_REPO`, `FORGEJO_PAT: ${{
     secrets.FORGEJO_SYNC_PAT }}`, `SUMMARY` from step 2's stdout; PAT (not
     FORGEJO_TOKEN) so the PR EVENT fires deploy.yml's farm leg —
     FORGEJO_TOKEN-authored pushes are anti-recursion-suppressed
     (RESEARCH-forgejo-runner [5]; DECISIONS).
  4. Else log "no changes" and exit clean.
