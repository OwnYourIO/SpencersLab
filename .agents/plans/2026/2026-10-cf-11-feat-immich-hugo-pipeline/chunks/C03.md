  byte-identical — regression-gated)

  current hardcoded 5-label act set (moved from template into values so the
  docker render is unchanged); host releases override with their own labels.
- Everything backend-conditional keys off `runner.backend`.

**values.yaml — app-template conditionals (docker-only today):**
- `initContainers.dind`, VCT `docker-data`, persistence `socket` (emptyDir),
  env `DOCKER_HOST` — each gated OFF in host mode (`CREDENTIALS_DIRECTORY`
  stays both modes).
- VCT `data`: docker 2Gi (unchanged); host releases override size via their
  service slice (20Gi — workdir + LFS checkouts + hugo cache + sync state).

**templates/secret-runner.yaml — backend-aware config.yaml:**
- docker: exactly today's config (`container: {privileged: false}` + labels
  from values).
- host: no `container:` block; adds `host: {workdir_parent: /data/workdir}` +
  `cache: {enabled: true, dir: /data/cache}`; labels from values.
- Everything else identical (capacity 1, timeout 30m, shutdown_timeout 5m,
  uuid/token_url/server.connections.default, release-named ExternalSecret).

**Image:** host releases override the container image via their top-level
slice — `ghcr.io/ownyourio/forgejo-host-runner`, `tag: main`,
`pullPolicy: Always` (no pinned tag yet; pin `:v<run>` once CI publishes, per
the image-tag rule). No probes on the runner container in either mode (no
health endpoint — verified by the predecessor ticket).
