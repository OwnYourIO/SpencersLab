## Conventions
- Evidence for a "dead upstream" ruling = a live anonymous probe against the upstream's own API/registry (status codes cited), plus the runner-side symptom reproducing locally. Anything without both is treated as a config bug until proven otherwise.
- Renovate config fixes must stay RE2-safe (the runner may have RE2; lookaheads silently fail there). Local emulations run on JS RegExp — a pattern passing locally is NOT RE2-proven; only literal `https?://`-style captures count.
