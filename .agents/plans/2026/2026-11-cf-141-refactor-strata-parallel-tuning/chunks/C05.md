## Goal

Make the strata build survive the current Canonical-mirror outage: rewrite the runtime
stage's single ubuntu-mirror `apt-get` RUN (`containers/strata/Dockerfile` L79–81,
`build-essential git ccache` on the `0.2.13-rocm-gfx120x` base) to the owner-directed shape,
as the coord ruling records it: **official-first, fallback-on-failure** — plain `apt-get
update` tried; on non-zero exit a `sed` re-points BOTH stanza hosts
(`archive.ubuntu.com`, `security.ubuntu.com`) in the deb822 `/etc/apt/sources.list.d/
ubuntu.sources` to `http://mirrors.edge.kernel.org` and retries — never an unconditional
mirror re-pin, so the fallback self-retires when the mirrors heal. **No engine/version/label
changes: the FROM pair, clone tag, engine label dirs, checkout markers, chart drafting pins,
and the README tag→digest ledger all stay byte-untouched.** The alpine `apk` step (L59) is
out of scope — different mirror family, no reported failure. PR-3 on the cf-141 branch;
authority: DECISIONS "Owner directive — CI delta (2026-11-11)" (owner's verbatim sed +
"something like").

## Tasks

- [ ] **Task 1 — the fallback rewrite** (the only ubuntu-mirror apt RUN in the file; one RUN
  step in place of one, preserving step count/order laws):
  target shape (quoting/brace form dev-verified under the base's `/bin/sh`):

  ```
  RUN apt-get update \
      || { sed -i 's|http://archive.ubuntu.com|http://mirrors.edge.kernel.org|;
             s|http://security.ubuntu.com|http://mirrors.edge.kernel.org|'
             /etc/apt/sources.list.d/ubuntu.sources \
             && apt-get update; } \
      && DEBIAN_FRONTEND=noninteractive apt-get install -y --no-install-recommends build-essential git ccache \
      && rm -rf /var/lib/apt/lists/*
  ```

  Why-comment in repo comment law (why-only, no outage narration, no dates — the outage is

  semantics verified so the sed NEVER runs when the official update succeeds (the
