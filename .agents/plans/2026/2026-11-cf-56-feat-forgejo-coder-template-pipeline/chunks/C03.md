## Acceptance criteria
1. `python3 -c 'import yaml,sys; yaml.safe_load(open(...))'` on the workflow parses.
2. Trigger shape: exactly `push` (main + the templates path filter) +
   `workflow_dispatch` (the `templates` input, all four keys); NO `pull_request` key
   anywhere in the file.
3. Guard shape: every job `if:` uses `contains(vars.ROLE, 'dev') || contains(vars.ROLE,
   'prod')` — no `== null` clause (the narrow-on-unset polarity, grep-pinned).
4. Shape: `concurrency.cancel-in-progress` is `false`; the push job has `needs`,
   `fail-fast: false`, the matrix over `fromJSON(...changed-templates)`, and NO
   `container:` field anywhere in the file (the job-image-as-today shape — the
   `runs-on: ubuntu-24.04` line is the whole routing); NO image/tag line of any kind
   in the file.
5. Env-only doctrine: every `secrets.`/`vars.` reference is inside `env:` blocks;
   the EXACT set of `vars.`/`secrets.` keys referenced is `vars.CODER_URL` +
   `secrets.CODER_SESSION_TOKEN` (the OQ5-minimal ruling — any further value-var
   reference reddens); zero occurrences of the instance URL literals
   (`coder.dev.scifi.farm`, `coder.spencerslab.com`) and no token-shaped literal in
   the file.
6. The detect step invokes `scripts/coder-template-detect.sh detect`; the push step
   invokes `scripts/coder-template-push.sh` with the matrix template; the diag step
   calls `coder version` (the D43 toolchain check); the detect job's checkout pins
   `fetch-depth: 0`.
7. Runbook parity suite green: every UA command block cites the EXACT var/secret
   names (joined-literal needles, the fanout-runbook technique so the suite never
   self-matches), the human-executed marker per command block, the banned-verb sweep
   (no kubectl, no helm install/upgrade/apply, no `coder templates delete` outside the
   user-owned posture section — token MINTS via `coder tokens create` are the only
   coder verbs allowed), the UA3 label-pin leg cites the four-act-label shape + the
   hand-bump law, and the postures stated as answers (the warn-and-skip, the 401-red,
   the TTL non-re-assertion, the delete/rename user-owned lines present).
8. `bash -n` + the full suite set (plan Commands) green, including the C01/C02 suites
   (no regression from C03's files).
