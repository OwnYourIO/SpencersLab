## Goal
The owner ruling (OQ3) retargets the CLI acquisition: the official Coder CLI joins the
existing `helm`/`cr` bake in `containers/forgejo-runner` — the D33/D43 house posture
(toolchain bakes at image build time, on the `containers-build.yaml` egress lane that
production already proves; workflow jobs install nothing). No new image: the workflow's
push job runs on the lab's job image as today (`runs-on: ubuntu-24.04`, no
`container:` field — the shape of the other four non-renovate workflows), and the CLI
is behind the label those labels already route to.
