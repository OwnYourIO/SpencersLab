# C06: `preload_board` payload — every card by swimlane and list, with checklist state, labels and both card ids
size: L   wave: 2   depends_on: [C01]

## Goal
Turn the claim-time preload into the one read the pickup walk actually reasons with: **all** cards grouped swimlane → list (with the titles, not just ids), each card carrying its two ids (the WeKan `_id` and the display `cardNumber` — the "AD-106" number), its labels, its `slug`, its archive flag, and now its **checklist state** — while staying one request and staying lean (no titles, no descriptions, no comments).

## Tasks
- [ ] `containers/wekan-mcp/wekan_mcp/server.py`, `preload_board`: add `checklists` to the export `fields=` trim so checklist state arrives in the same single request (today the trim omits the section and the payload returns empty arrays); per card emit `checklists: [{id, title, items: [{title, finished}]}]`, **filtered** to the kickoff-relevant set — the five standard checklists (`Services`, `Type`, `Model(s)`, `Lifecycle`, `Human in the Loop`) plus the legacy `Research` checklist and, when present, a legacy 8-item Lifecycle spelling — everything else stays out (the "improve / filter" half of the ask). Item **titles** must be included: `get_checklist` already proves titles are readable on the deployed build (EXPLORE §0 correction), so no design may assume otherwise.
- [ ] Grouping: emit swimlane and list **titles** alongside their ids (`{id, title, cards: […]}` per list, `{id, title, lists: […]}` per swimlane) so the consumer's Test/Finished/Timeout membership tests stop needing a separate `list_lists` round-trip; keep the board's own sort order and the flag-not-drop discipline for unknown parents.
- [ ] Optional filter argument: `swimlane_titles: Optional[list[str]]` (default: every swimlane) so a run can pull `In Process` alone, or `In Process` + `Backlog` when it needs the Inbox/dependency context — the payload bound the OQ3 budget argument cares about. Documented default = all swimlanes ("all cards on the board by swimlane and list").
- [ ] Keep the seven lean per-card fields (and C01's stack-parsed `slug`), keep `dependencies`, `label_names`, `field_names`; add nothing that re-introduces card titles/descriptions. Docstring restates the exact field set and the checklist filter rule.
- [ ] boards skill, `Preload consumer at claim`: the payload description updated to name the new fields (checklist state incl. the filter set, swimlane/list titles) and to say what they let the run skip — the kickoff checklist consumption and the legacy-vs-Lifecycle checklist detection for candidates — while the per-card `get_card` **stays for the claimed card only** (description, custom fields). The "never the hook" sentence and the probe/absent/failed degrade law stay byte-familiar (`tests/boards-deps` t2 pins their co-location).
- [ ] Docs: `skills/wekan-mcp/SKILL.md` tool description + `skills/wekan-mcp/references/call-shapes.md` preload row; the `cf96-deploy` readback runbook's preload shape check updated.
