# C01: Slug stack — append `[slug](session link)`, newest-last parse; plus this ticket's scope admits
size: M   wave: 1   depends_on: []

## Goal
Make the `slug` custom field an append-only stack of combined `[<slug>](<session link>)` lines: a run never clobbers a different slug already in the field, it appends `\n` + its own line, and the run's own slug is the **last** bracketed entry. One parse authority, server-side and skill-side, that tolerates the mixed live shapes already on the board.

## Tasks
- [ ] boards skill (source; mirror regenerates): rewrite the Post-plan card write-back step 2 as a **read-modify-write** — read the current `slug` value (`get_card` of this run's card, which claim already does), then
  - value empty/unset → write `[<slug>](<session link>)`;
  - last line's bracketed text **equals** this run's slug → rewrite that line in place (idempotent refresh of the link half);
  - a **different** slug present → write `<existing value>\n[<slug>](<session link>)` (never drop a line, never reorder);
  - the retired `session` field is still never read or written.
