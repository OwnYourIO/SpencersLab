# C02: `agent-dev` → `agent-dev-pr` / `agent-dev-local`
size: M   wave: 2   depends_on: [C01]

## Goal
Replace the single pipeline implementer with two variants: `agent-dev-local` (commits, never pushes — the variant `-local` coords launch) and `agent-dev-pr` (additionally pushes the ticket branch for remote build/test, carrying the C01 skill). Everything else about the implementer contract stays byte-stable: the permission block (tests read-only, plans denied, generated surfaces denied, context-file allow/ask/deny table, MCP tiers), the MUST-load list, the `pipeline-role-dev` contract.
