## Goal
The card's checklist restructure, agent-side: the AI-Dev card checklist "Research" (None/Before Planning/After Planning/Agent Decides) becomes **Lifecycle** with the eight stages `Pre Research / Plan / Post Research / Test / Code / Review / Deploy / Single Session`, and the coords are directed to run ONLY the checked stages. The Research board LABEL (research-only trigger) is untouched.
