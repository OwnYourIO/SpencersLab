# C01: S3-gate the forgejo chart (helper + gated shape Secret + gated ESO + optional env legs) and flip dev to the local stance
size: M   wave: 1   depends_on: []

## Goal

One render: the forgejo wrapper chart renders S3-only artifacts iff the
merged values declare `gitea.config.lfs.STORAGE_TYPE: minio`; dev's slice
drops its S3 declaration (LFS stays on, local on the 10Gi data PVC); infra's
effective S3 config is unchanged (plan A9 — the render delta is exactly the
pinned four-item list). Chart gate and dev-slice edit are ONE chunk because
they are one render: the intermediate states (gated chart + still-minio dev
slice, or ungated chart + dev slice without shape keys) are both wrong.
