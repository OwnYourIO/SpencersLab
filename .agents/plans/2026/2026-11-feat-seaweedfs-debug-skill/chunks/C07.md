## Grounded semantics (verified 2026-11-11 — read before authoring anything)
- **The shipped matcher is flat and whole-value.** Extracted from the installed binary
  (`~/.nvm/versions/node/v26.5.0/lib/node_modules/@opencode/cli/bin/opencode.exe`, v2.2.6):
  `.replace(/\*/g,".*").replace(/\?/g,"."); if (s.endsWith(" .*")) s = s.slice(0,-3)+"( .*)?";
  return new RegExp("^"+s+"$","s").test(a)` — `*` matches ANY character INCLUDING `/`, `?` is
  one char, match is anchored whole-value. `**` is two `*` wildcards — identical to `*`, NOT a
  globstar. Corroborated by opencode.ai/docs/permissions ("`*` — zero or more characters,
  including `/`") and upstream issue #2900 (maintainer: "simple regex globbing"). The repo's
  fnmatch-based `policy.py` simulators reproduce this exactly — verdict assertions ride them,
  never a hand-rolled second matcher. (agents-sync permissions.md line 6 "`**` crosses
  directory boundaries" is misleading — `*` already crosses; C07 corrects that line.)
- **Last match wins** (docs + shipped `evaluate.ts` `findLast` + agents-sync convention).
- **The FRICTION-proposed shape is fatal twice.** `edit .agents/plans/*-*.md allow`:
  placed BEFORE the `.agents/plans/**` deny it is dead code (the later deny matches a superset
  and wins); placed AFTER it, `*` crossing `/` makes it match every per-ticket PLAN-OF-RECORD
  too (`2026/2026-11-…/2026-11-11-….md` has the same dated-name shape — the matcher is
  depth-blind, and no positive pattern can separate root from subtree by NAME). STATE.json,
  chunks/Cxx.md, FRICTION/DECISIONS happen to survive (no dash before `.md`), but the
  plan-of-record always carries >= 2 dashes — the naive allow re-opens exactly the file the
  bookkeeping deny exists to protect. Rejected.
- **Depth-2 deny is the minimal correct shape.** `.agents/plans/*/*` = `^\.agents/plans/.*/.*$`
  = "at least one `/` after `.agents/plans/`" = everything at depth >= 2: per-ticket folders,
  `templates/`. Depth-1 files (the root dated deliverables) fall through to `edit * allow`.
  Verified plans-root content (`git ls-files .agents/plans`): ONLY dated `*.md` deliverables
  plus the `2026/` and `templates/` directories — nothing else opens. Matcher dependency: if
  upstream ever ships segment-scoped globs, `*/*` silently narrows to exactly-2-segment paths
  and depth-3+ files fall through to allow — t7's verdict arms make that regression LOUD.
- **Scope is 7 sources, not 5.** The deploy pair `agent-dev-deploy(-pr).md` carries the
  identical deny AND is pinned by `tests/agent-dev-deploy/surface.sh` t2 as byte-equal to its
  `agent-dev-{local,pr}` baseline plus exactly the `opencode_worktree_remove` row — editing
  only the brief-enumerated five would redden t2. The alias law applies to the whole family:
  the same line lands on all seven in one commit.
