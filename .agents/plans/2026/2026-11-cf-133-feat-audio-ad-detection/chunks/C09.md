## Goal
Close the two post-C15 detection holes the owner ruled onto this ticket:
the **C15 asymmetry** (the `build-charts` detect body still dies on an
empty `before` with no marker, while `build-containers`' detect script
special-cases `workflow_call`) and the **bootstrap tip-only skip-and-seal**
(a first called run with no marker diffs `HEAD^..HEAD` — directories
introduced below a burst tip are invisible, both builders go green, the
marker seals at the tip, and the missed directories are never built). Plus
the C05 owner-leg runbook L1 reword for the post-C15 fan (push arm
retired; `main-sync.yaml` calls the workflows; the dispatch hatch is the
manual lane) and the post-C08 registry pull story.

**The branch is pre-C15.** C08's step-0 rebase brings in main's post-C15
shape (`build-containers.yaml`, `build-charts.yaml`, the marker-aware
`main-sync.yaml`, the marker-aware detect script). This chunk's workflow
edits land on the **post-C15 names** — never on the branch's pre-C15
`containers-build.yaml` / `release.yaml`.

  `containers/**`) + `workflow_dispatch` (the named rebuild hatch —
  "An empty list builds nothing") + `workflow_call` — **no push arm**
  ("the PR and dispatch lanes stay byte-frozen", C15/D56).
- `scripts/forgejo-container-detect.sh` (main): base chain **marker →
  (workflow_call, no marker: tip-only, `::warning::`-announced) → (all-zero
  `before`: tip-only, announced) → (empty `before`: `die 'push arm:
  EVENT_BEFORE is empty, which no push payload sends'` — scoped to real

  `bump_sha`); the marker resolver gate passes `push` + `workflow_call`
  ("the gate is written final so C15 removes the trigger, not this body");

  announced) → empty `before`: `exit 1` die — NO `workflow_call` arm**. A
  no-marker called run therefore dies. [The asymmetry.]
- `main-sync.yaml` (main): calls both builders on the prod-main fan
  (`if: contains(vars.ROLE, 'prod')`, `secrets: inherit`); `advance-marker`
  has `needs: [build-containers, build-charts]` (D54 single writer — `needs`
  IS the aggregate gate; a red fan leaves the marker put, so the next fan
  re-covers the range) and pushes `ci/last-built` to the `bump_sha` or the
  event sha (plain push; a refusal is a CLASSIFY).
- **The skip-and-seal consequence:** first called run on a prod instance
  with no `ci/last-built` ref (fresh instance, or the owner deleted the
  ref): the containers arm is tip-only `HEAD^..HEAD` (announced) — a
  directory introduced in a commit below the burst tip is invisible; both
  builders green → `advance-marker` seals the tip → the missed directories
  are never built until something later touches them.
- **Chosen fix (recorded):** on a no-marker first called run, a
  **wider-base diff — the full set** (empty-tree base, announced) on
  **both** detect surfaces, plus the build-charts `workflow_call` arm
  before the die. **Rejected fix (documented):** refusing to advance the
  marker on a multi-commit push — (1) it does not resolve the skip: the
  next no-marker called run is still tip-only, deferral is not coverage;
  (2) it defeats the marker's re-cover property (C14/D53 — the marker base
  is what makes a dead run's lost work re-covered by the next fire); (3) it
  cascades into the main-sync D54 single-writer job and the
  `forgejo-main-sync.sh` test — cf-55 territory, outside this ticket. The
  chosen fix is a one-time, announced, bounded full build (the marker
  exists after the first green fan; the seal becomes honest).
- **Cross-suite impact (verified):** main's `tests/services/
  forgejo-build-containers.sh` pins the base chain "marker→tip-only→before
  with the A5 die first" (line 24) + a textual pin of the tip-only
  fallback (line 962); `forgejo-build-charts.sh` re-aims the old silent
  empty-before fallback "to the loud-die" (line 88). The branch's old-named
  `tests/services/forgejo-containers-build.sh` is **absent on main**
  (renamed by cf-55 r5). C09's behavior change breaks the two main-side
