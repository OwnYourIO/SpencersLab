# C02: Commit policy — coord owns commits, pipeline implementers lose commit
size: M   wave: 1   depends_on: []

## Goal

Card note 4: "agents shouldn't commit so often … give the coord agents privs
to git commit and let the coord manage that" (except delicate branch work).
Coords ALREADY hold `git add *`/`git commit *` allows and commit each chunk
(verified 2026-10-29: agent-board-coord-local source + pipeline-role-coord
§git); the change is to stop the pipeline implementers from committing, make
coord the explicit sole committer (one commit per chunk: code + tests +
state), and leave every standalone agent and every "delicate branch work"
surface untouched (D7).
