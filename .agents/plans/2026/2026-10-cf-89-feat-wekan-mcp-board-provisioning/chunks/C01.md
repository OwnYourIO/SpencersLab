## Interface (pinned — tests assert these signatures/routes verbatim)
```python
@_write_tool
def update_board(board_id: str, title: str) -> dict
```
- `PUT /api/boards/{board_id}/title` body `{"title": title}`. Guard: response must be a dict with `_id == board_id`; a dict with `error` or a missing `_id` → `WekanError` (never trust 200). Hydrate via `GET /api/boards/{board_id}` (full board doc; `_slim_board` itself NOT widened). Return `{id, title, key, color, permission, archived, renamed: true}`; a failed read-back nulls the echo fields and logs a warning — the rename already succeeded (precedent: `create_list` hydrate degrade). Gate docstring: `checkBoardAdmin` at v12.65 (member → 403, title unchanged); 404 = board not found/not visible; cardNumber sequence lives in the `Counters` collection and survives by construction (v12.65 stamp). `key` mention once: auto-assigned, REST-immutable.

```python
@_write_tool
def create_swimlane(board_id: str, title: str, sort: Optional[int] = None) -> dict
```
- `POST /api/boards/{board_id}/swimlanes` body `{"title": title}` plus `sort` only when given (finite int; server honors it since #3624, else max(live sort)+1 over `archived:false` siblings). Guard: response dict must carry `_id` — no `_id` ⇒ `WekanError("... no id ...")` regardless of status. Hydrate via `GET /api/boards/{board_id}/swimlanes/{id}` (single route carries `sort`; collection route projects it away). Return `{id, title, sort}`. Gate: `checkBoardWriteAccess` (v12.65 stamp).

```python
_LABEL_COLORS = ( …the 25 config/const.js names, incl. white… )  # module constant, v12.65 stamp

@_write_tool
def create_label(board_id: str, name: str, color: str = "green") -> dict
```
- Client-side: `color` must be in `_LABEL_COLORS` BEFORE the request — unknown/hex → clean tool error listing the allowed names (card's "hex rejected with a clear tool error"). Send `{"label": {"name": name, "color": color}}` to `PUT /api/boards/{board_id}/labels`. Response branch: bare JSON **string** (non-empty) ⇒ label id (new, or existing — (name,color)-idempotent); dict ⇒ embedded-error guard → `WekanError`. Return `{label_id, name, color}`. Docstring: idempotent on (name,color); same name + different color creates a SECOND label; server 400 (`Invalid label color …`) stays the authority; gate is board-admin-or-site-admin; v12.65 stamp.

```python
@mcp.tool
def list_board_members(board_id: str) -> dict
```
- `GET /api/boards/{board_id}` board doc. Guard: must be a dict with `_id` and `members` a list (else embedded-error `WekanError`). Return `{board_id, title, members: [{user_id, is_admin, is_active, is_no_comments, is_comment_only, is_worker, is_normal_assigned_only, is_comment_assigned_only, is_read_only, is_read_assigned_only, username: null}], username_resolution: "WeKan publishes usernames only on site-admin-gated routes (GET /api/users[/:userId]); the service user is not site admin — resolve names out-of-band"}`. Nine normalized booleans (present⇒true, absent⇒false); `grantedBy` provenance omitted. NO user-lookup probe code (grep must stay clean).

Shared guard: one small plain helper (e.g. `_embedded_error(resp, path)` / expected-key asserts) — NOT a registered tool.
