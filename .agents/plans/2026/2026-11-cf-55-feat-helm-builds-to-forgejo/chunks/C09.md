## Goal

Make a stale `Chart.lock` unable to poison a release fire: the bump job
regenerates locks (full tree) alongside every version bump, the test-build
smoke stops aborting on drift, and the three charts currently drifted at
`3f21e85e8` — {base, traefik, traefik-zerotrust} — get their locks
regenerated and committed in this chunk so main is drift-free at merge
(RESEARCH.md:1145-1153 "RECOMMENDATION: BOTH, pipeline as the guarantee";
drift scan RESEARCH.md:899, :1418 item 83; owner Q2 directive "Chart.lock
regeneration OWNED BY THE PIPELINE (self-heal)" — STATE.round4_directive).

## Evidence the design rests on (cite-back map)

- `helm dependency update` is the only regen verb (no `--force-update` on
  dep subcommands — RESEARCH.md:1069-1075 [70][71][78]); on a fresh lock it
  is a byte-no-op (digest-equal ⇒ no rewrite — RESEARCH.md:1061-1064 [72]),
  so the full-tree pass is cheap on churn, and its per-chart network cost ≈
  what `cr package charts/*/'s whole-tree Build() already pays every fire
  (RESEARCH.md:1087, :1118-1121 [79]).
- `cr package` Build()s EVERY chart EVERY fire ⇒ one drifted chart outside
  the changed matrix kills the release + forgejo-publish legs (blast radius
  = the whole tree — RESEARCH.md:1092-1096, :1118-1121). Hence FULL-TREE
  heal, not changed-set-only (RESEARCH.md:1118-1121 "the safe shape is
  full-tree heal in bump").
- The top-level chart `version:` is NOT in the digest inputs
  (RESEARCH.md:1053-1056 [73]) ⇒ a bump-then-heal (or heal-then-bump) order
  inside one commit never invalidates the lock: locks + versions in ONE
  bump commit is digest-safe by construction.
- `dep update` auto-adds unknown repos (`ensureMissingRepos` —
  RESEARCH.md:1065-1067 [72]) ⇒ the bump job needs no repo-add step; it
  gains upstream-egress exposure earlier (same class the release leg
  already has — RESEARCH.md:1114-1117), which the header comment must
  re-truth.
- Job order is `test-build → bump`: if test-build keeps aborting-loud on
  drift (`helm dependency build` aborts BEFORE downloads — RESEARCH.md:
  1045-1052, :1089-1091), bump never runs and the self-heal can never fire
  on the drift-carrying push. Therefore test-build flips to `update`
  (ephemeral heal on the matrix copy, never pushed) — the plan ruling over
  the abort-loud alternative; the repo-side drift SIGNAL moves to the new
  hermetic lock-consistency leg (t24) which runs before any merge.
