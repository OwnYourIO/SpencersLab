## Goal

Create the custom Forgejo job image the D33 ruling demands: `containers/
forgejo-runner/` publishing `ghcr.io/ownyourio/forgejo-runner` (and the
instance-registry twin, automatically — detection is path-based, there is NO

image is `catthehacker/ubuntu:act-24.04` at a pinned digest PLUS helm and cr
baked at `/usr/local/bin`, so runner jobs install nothing at run time. Ships
with its static contract suite `tests/containers/forgejo-runner.sh`.
