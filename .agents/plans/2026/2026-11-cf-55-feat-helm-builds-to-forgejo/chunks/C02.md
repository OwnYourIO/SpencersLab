# C02: Move the container build pipeline to Forgejo Actions (dual push, date tags, registry cache)

size: L   wave: 1   depends_on: []

## Goal

`.forgejo/workflows/docker-build.yaml` becomes the single container build
authority on the prod Forgejo runner: same change-detection and matrix shape as
today, one build per container published DUAL (ghcr.io/ownyourio + the instance
OCI registry), immutable tags switched to the owner-ruled date scheme
`v<UTC-YYYYMMDD>.<HHMM-base10>.<run_number>` (semver-comparable, disjoint from
the legacy `v<N>` space), buildx cache on `type=registry` at
`ghcr.io/ownyourio/<container>-buildcache:<branch>`, while
`.github/workflows/docker-build.yaml` is deleted in the same commit. No chart
pin, no consumer value file changes.
