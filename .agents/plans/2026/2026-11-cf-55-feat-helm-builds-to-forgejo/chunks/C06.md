# C06: Re-point the runner label map to the baked image (chart + dev/gpu suites)

size: M   wave: 2   depends_on: [C05]

## Goal

Make every act-24.04-family runner label resolve to the baked job image on both
deployments (dev + gpu aliases share the chart default; the per-cluster slices
override only url/identity, §F2). This is the wiring half of D33: after it (and
C07) the release pipeline's jobs can find helm without egress. The two runner
suites flip with it — their ACT_LABELS constants, the g2/t2 set-equality legs,
the t14 record leg and the **g7 blast-radius tripwire** (which today forbids
exactly this change and must be re-armed, not removed).

   pass (PATH law); the rendered Secret's `config.yaml`
   `server.connections.default.labels` set equals the new ACT_LABELS (dev
   t2/check_release + gpu g2 prove it on real renders).

   `GPU_RUNNER_DIFF_BASE=origin/main bash tests/services/gpu-forgejo-runner.sh`
   passes (g7 armed, not amputated — a mutation re-pointing a NON-label line
   or moving the act-22.04 line reddens it; review proves teeth).

   chart default; §F2 slices carry only url/identity).
5. `charts/forgejo-runner/Chart.yaml` untouched (no hand-bump — the release
   pipeline bumps it at the merge fire).
