## Goal
The C17 deploy froze because `podManagementPolicy` is immutable-for-update: the
STS patch was API-REJECTED (verb-independent validation — PATCH and PUT both
refuse it), ArgoCD marked SyncFailed, the reloader then poked the OLD template
onto pods (gpu-9 crashed on the retired `runner-creds` subPath key), and
kubelet's auto-created EMPTY `/data/config/config.yaml` leaves on PVCs 0-8 read
as "registered" to C17's existence-only guard. C18 (owner ruling 2026-11-27,
"Run C18, then unstick by sync"): (a) put the ArgoCD replace-and-recreate sync
option on the runner STS so this class can never freeze a rollout again;
(b) make the register guard CONTENT-validate before it skips, so empty leaves
and half-written pairs re-register instead of crash-looping; (c) suite legs
pinning both, including an executable EMPTY-LEAF battery; (d) a values-header
note. Rides C17's landed files (branch tip, chart 2026.11.3).
