# C02: Renovate coverage for every pinned artifact
size: M   wave: 2   depends_on: [C01]

## Goal
`renovate.json` keeps every pinned artifact in the new `containers/coder-workspace/Dockerfile` current: base image, node, go, helm, kubectl, uv, fj, @opencode/cli, @openchamber/web — with helm constrained to the v3 line and kubectl to the cluster minor.

## Tasks
- [ ] Add a new regex custom manager for `/(^|/)containers/[^/]+/Dockerfile$/` that captures the datasource from the renovate comment line immediately above an `ARG`. Starting point (schema-validated in a prior session): `/tmp/opencode/probe-renovate.json` (the last `customManagers` entry). DELTA over the probe: the datasource capture must be NARROWED to `node-version|golang-version|forgejo-releases|npm` — NOT the probe's generic `[a-z-]+`. Rationale (DECISIONS #15): the pre-existing git-pin manager already captures `github-tags|github-releases|git-refs` ARG lines (helm/kubectl/uv); a generic capture double-matches those and produces duplicate-dependency warnings.
- [ ] Add two `packageRules` (from the probe): `matchPackageNames: ["helm/helm"]` + `matchNewValue: "^v3\\."` (ArgoCD renders with helm v3) and `matchPackageNames: ["kubernetes/kubernetes"]` + `matchNewValue: "^v1\\.36\\."` (cluster k3s v1.36.x). Give each a `description`.
- [ ] Do NOT touch any existing manager/rule; do not add a manager for the `FROM` line (renovate's built-in dockerfile manager tracks `debian:13-slim@sha256:...` digests natively); do not add a `.tf` manager (deferred, DECISIONS).
