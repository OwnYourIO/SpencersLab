# C04: New `coder-templates/kubernetes-hardened/` template (restricted PSS + rebuilt image)
size: M   wave: 3   depends_on: [C01, C03]

## Goal
Add a NEW server-side Coder template `kubernetes-hardened`: the existing template's shape (namespace, cpu/memory/home-disk params, per-workspace home PVC, `/shared` mount, apps, dashboard metadata) merged with the hardened contract — the rebuilt `ghcr.io/ownyourio/coder-workspace` image, restricted Pod Security Standards, the single baked startup script (no runtime installs), code-server on the home PVC, and the documented 1-week autostop convention. Existing workspaces keep the untouched `kubernetes` template.
