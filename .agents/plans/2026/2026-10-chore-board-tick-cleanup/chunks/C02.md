- Self-identification (OQ3 confirmed): the run uses the sessionID from its own `session_rename` if it already renamed; otherwise it calls `tools.opencode.session_rename({title: "no-op <yyyy-mm-ddThh:mm>"})` — the current-session form returns the id deterministically, the grant already exists on all six coord variants, no new permission rows, and the title is the human breadcrumb.
