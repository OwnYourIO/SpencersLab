# C01: forgejo-runner → single-instance chart, deployed twice via `chart:` alias (atomic)
size: L   wave: 1   depends_on: []

## Goal
`charts/forgejo-runner` becomes a ONE-instance chart (one StatefulSet + dind
sidecar, one headless Service, one ExternalSecret, one creds persistence
entry) deployed TWICE by the dev ApplicationSet — `charts.forgejo-runner-dev`
and `charts.forgejo-runner-infra`, both aliased `chart: forgejo-runner` —
one ArgoCD Application per target Forgejo instance. The runner behavioral
contract (image pins, dind shape, act labels, timeouts, declarative
registration) is preserved byte-for-byte in spirit; names become
release-derived so two releases coexist in namespace `default` without
collisions. Lands as ONE commit (chart + service values + custom-values).
