# C03: Activate git-SSH on dev+infra (values + forgejo chart) + operator notes
size: M   wave: 2   depends_on: [C02]

## Goal

Flip the switch: set `gitSshPort: 22222` in BOTH service umbrellas (dev +
infra) so the base chart renders the Gateway API surface on exactly those two
clusters, and configure the shared forgejo wrapper chart to (a) advertise the
port in clone URLs (`SSH_PORT: 22222` — the subchart hardcodes 22 and its
auto-follow is dead code) and (b) attach each instance's `<fullname>-ssh`
Service to the cluster Gateway via the subchart's shipped `tcpRoute` block.
Finish with a short operator/client-migration note in `.agents/notes/`.

## Tasks

- [ ] `services/dev/prod/values.yaml`: add top-level `gitSshPort: 22222`
      (with a WHY-comment: git-over-SSH exposure for the forgejo instance;
      consumed by charts/base traefik HelmChartConfig + tcproutes CRD gate;
      must equal the forgejo chart's SSH_PORT).
- [ ] `services/infra/prod/values.yaml`: add top-level `gitSshPort: 22222`
      (same comment, infra-flavored).
- [ ] `charts/forgejo/values.yaml`: under the `forgejo:` subchart key add
      `gitea.config.server.SSH_PORT: 22222` (WHY-comment: advertised in
      clone URLs; must equal the clusters' gitSshPort; subchart default 22 +
      dead auto-follow force the explicit set) and enable the subchart's
      shipped TCPRoute:
      ```yaml
      tcpRoute:
        enabled: true
        parentRefs:
          - name: traefik-gateway
            namespace: kube-system
            sectionName: gitssh
      ```
      (port omitted → defaults to `service.ssh.port` 22; backend =
      `<fullname>-ssh`, i.e. dev-forgejo-ssh / infra-forgejo-ssh — the live
      ClusterIP Services, unchanged).
- [ ] Add `.agents/notes/<yyyy-mm-dd>-forgejo-git-ssh.md`: client migration
      notes — new ssh:// URL shape per host+port, the `~/.ssh/config`
      `Host ... / Port 22222` trick that keeps scp-style URLs AND fixes
      `coder gitssh`, one-time known_hosts `[host]:22222` prompt (host keys
      unchanged on the PVCs), and "port 22 on the git hosts is still the
      node sshd".
- [ ] Full plan Commands pass (lint + renders + sentinel sweep + greps).
