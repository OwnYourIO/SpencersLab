## Goal
One `mcp-actual-budget` ToolHive MCPServer on the home cluster running the `sstefanov/actual-mcp`
image (s-stefanov/actual-mcp — 294★, pushed 2026-11-23, e2e-gated against a real server; the
owner's replan ruling 2026-11-24 — the agigante80 pick is DROPPED, not postponed: it is
password-only with no `sessionToken` slot, so it could never carry the owner's chosen
credential). Wired to the wuulf budget (C01) through the in-cluster service URL,
Bearer-authenticated on the MCP side, and credentialed to Actual via
`ACTUAL_SESSION_TOKEN` — the sessionToken slot in which the wuulf budget-scoped API key is
passed (Post Research Q2: keys are passed as `sessionToken`, docs-confirmed) — so binding #4
(26.12+ budget-scoped API keys) is satisfied the day the keys ship: **drop the key into the
same variable, no code change, no session-token stopgap**. The first tier ships
**WITHOUT `--enable-write`** — the flag's absence is the read-only boundary the owner ruled.
