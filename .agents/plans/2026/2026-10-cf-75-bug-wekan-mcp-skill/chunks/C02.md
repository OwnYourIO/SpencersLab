# C02: coord routes validation fixes automatically
size: M   wave: 1   depends_on: []

## Goal
Per the card's last paragraph: a `validation_at_fault` review verdict no
longer costs a user question. The coordinator routes the fix straight
back to the test session that authored the validation; the user is asked
ONLY when the fix would modify functionality (the validation encoded a
real requirement and repairing it means changing what the plan/build
does) — then it is a plan question, not a routing question. Covers the
duplicate card #74 ask (OQ3).
