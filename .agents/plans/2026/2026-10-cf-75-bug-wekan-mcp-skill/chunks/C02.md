## Goal
Per the card's last paragraph (OQ6 + OQ3 resolved 2026-10-27): a
`validation_at_fault` review verdict no longer costs a user question.
MECHANICAL validation repairs route **silently** — the coordinator sends
the fix straight back to the test session that authored the validation,
no question at all. The TEST session flags NEEDS_INFO when a fix would
instead modify functionality (the validation encoded a real requirement
and repairing it means changing what the plan/build does); only then
does the coordinator escalate to the user — that is a plan question, not
a routing question. Card #74's duplicate ask is covered here; moving #74
to Review at run end is a coord board-side duty (DECISIONS).
