## Goal
Ship `skills/wekan-mcp/` as the one skill an agent loads for ANY work
against the lab's wekan-mcp servers (`dev-boards`, `admin-global-wekan`,
`readonly-global-wekan`): what the servers are, every tool's call shape,
the projection gotchas, the failure modes with their recoveries, and the
Board context block schema — so nobody rediscovers them via validation
errors. Land the absorbed content of the draft ergonomics ticket here
(OQ2 resolved 2026-10-27: YES absorb; retirement is coord bookkeeping,
see below) and cross-reference `wekan-api` without duplication.
