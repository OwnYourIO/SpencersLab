# C03: agent-board + /wekan-board-context collector + consumption rule
size: M (agent) + M (command + rule)   wave: 2   depends_on: [C01]

## Goal
Give agents a board-MCP worker (`agent-board` — OQ4 resolved 2026-10-27:
in scope) and a one-shot collector
command (`/wekan-board-context`) that emits the Board context block per
the schema C01's skill defines, so the OpenChamber scheduled-job prompt
can carry it and a board-coord run starts with board/swimlane/list/
custom-field/label IDs already resolved instead of burning the first six
MCP round-trips (and the run-start catalog-gap class with them).
